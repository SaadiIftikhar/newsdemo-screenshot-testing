Demo without slides

Show the project itself: the repo, the app, the tests and a regression being caught. About 15–20 minutes. Run 1 · Before the presentation first. For each step: say the line, then copy and run the command.

Tips

  • Say the line before you run the command, so people know what to look for.
  • Step 5's failing run is the point of the demo. Say so before you run it.
  • Short on time? Start at section 5.
  • If something breaks: git checkout main, then show the captured result: open docs/regression.

1. What's in the repo

  1. One repo, one small news app in SwiftUI, and one folder of fake data that every test uses.

    VS CodeOpen the project.
    open -a "Visual Studio Code" .
    You'll see: fixtures/, ios/, scripts/, docs/, Makefile.

  2. Every action is one make command; here they all are.

    TerminalList the commands.
    make help
    You'll see: ios-test, ios-ui-test, lint-goldens, gallery, ios-record, ios-run…

2. The app itself

  1. The app runs on fake data: a feed, games and an account. Tap the PLUS article (the Tesla one): without a subscription you get the paywall. Log in as demo@newsdemo.app / demo1234 and it opens.

    SimulatorOpen the app.
    make ios-run
    You'll see: The NewsDemo feed in the simulator.

5. Break it on purpose

  1. This branch is a plausible refactor: one file. It drops the PLUS badge and tightens the banner by 2 points.

    TerminalShow the change.
    git diff main demo/regression --stat
    You'll see: 1 file changed.

  2. Switching to the branch with the bug.

    TerminalCheck out the branch.
    git checkout demo/regression
    You'll see: Switched to branch 'demo/regression'.

  3. This should fail. Watch how many screenshots catch it.

    TerminalRun the tests.
    make ios-test
    You'll see: ~1 min, fails: 29 failures.

  4. Approved picture, new picture, changed pixels in magenta. Scroll to teaserCard_premium: the badge is gone.

    BrowserOpen the diff page.
    open artifacts/ios/diffs/index.html
    You'll see: golden | new | magenta diff.

  5. The triage table the CI bot posts on the pull request.

    TerminalShow the summary.
    cat artifacts/ios/diffs/summary.md
    You'll see: 29 changed: 10 layout, 19 visible, 0 subtle.

  6. Back to the correct code. Always.

    TerminalSwitch back.
    git checkout main
    You'll see: Switched to branch 'main'.

6. What happens next: a human decides

  1. A bug, like here: fix the code, the goldens stay. This pull request is blocked.

    BrowserThe regression PR.
    open https://github.com/SaadiIftikhar/newsdemo-screenshot-testing/pull/1
    You'll see: Red check and the bot's triage table.

  2. An intended change: CI re-records the goldens and a code owner approves them. This PR did exactly that.

    BrowserThe redesign PR's commits.
    open https://github.com/SaadiIftikhar/newsdemo-screenshot-testing/pull/2/commits
    You'll see: A "snapshot-bot" commit: "re-record iOS goldens".
