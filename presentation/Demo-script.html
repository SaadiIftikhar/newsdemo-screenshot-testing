If they ask

"Who approved the goldens?"
I did, as code owner. AI may triage; a human approves and merges.
"Fails on CI, passes on my Mac?"
CI is the source of truth. Download the diff artifact from the run, and use the same pinned simulator to reproduce it.
"How small a difference is allowed?"
Only invisible rendering noise (perceptual precision 0.98). Anything visible fails; tolerance is never loosened globally.
"How fast at scale?"
12–19 min per PR on GitHub today; at scale, only affected modules, sharding, slow checks nightly.
"Flaky tests?"
No automatic retries; quarantine within 24 hours with an owner, then fix the cause.
"Why only iOS?"
The brief asks for one platform plus a strategy for both; Android is STRATEGY §10.
